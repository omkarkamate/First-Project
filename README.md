# Stress Level Prediction Web Application



##  Live Demo
🔗 https://stress-level-1.onrender.com


---

##  Project Overview

This project is an end-to-end Machine Learning web application that predicts a user's 
**Stress Level** based on lifestyle habits, device usage patterns, and productivity metrics.

The application is fully deployed on Streamlit Community Cloud and provides real-time predictions through an interactive web interface.

---

## Problem Statement

Excessive device usage, poor sleep patterns, and work-related stress are common in modern lifestyles.

The goal of this project is to build a Machine Learning model that predicts stress levels using:

- Demographic information
- Device usage behavior
- Productivity metrics
- Lifestyle indicators
